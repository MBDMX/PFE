1. Vision de l'Architecture (Full-Stack)

Le projet est structuré comme un écosystème Monorepo permettant une synchronisation parfaite entre le terrain et le bureau.

Backend (FastAPI)

Moteur asynchrone gérant le Machine Learning et les flux SAP. Utilisation de Prisma ORM pour une base de données PostgreSQL robuste et type-safe.

Frontend (Next.js 15)

Interface réactive basée sur le concept de PWA (Progressive Web App) pour supporter le mode offline et une UX de type native sur mobile.

2. Innovations IA & Machine Learning

Contrairement aux logiciels classiques, notre solution est "intelligente" par design.

Algorithme Isolation Forest (Health Score)

Le fichier ml_service.py implémente un modèle non-supervisé qui calcule un score de santé en temps réel.

  • Feature Engineering : Calcul automatique du MTBF (Fiabilité) et MTTR (Maintenabilité).
  • Hybrid Scoring : Fusion entre le score d'anomalie statistique et les règles métier SAP.

Recherche Sémantique (Smart Search)

Grâce à ai_search.py, l'application comprend l'intention technique de l'utilisateur (Fuzzy Matching + Dictionnaire de connaissances métier).
